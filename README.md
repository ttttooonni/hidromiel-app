# Hidromiel v3

PWA local y offline, sin dependencias externas.

## Incluye
- Interfaz móvil renovada: cercana, cálida y rápida.
- 9 recetas iniciales: tradicionales, melomels, metheglin, bochet, cyser, pyment y una variante canaria.
- Guía práctica.
- Trucos y diagnóstico de problemas.
- Cuaderno de lotes.
- OG/SG con validación y ABV estimado.
- Historial de mediciones de SG, temperatura y pH.
- 7 hitos del proceso.
- Fotografías por lote en IndexedDB.
- Copia completa JSON con datos + fotos.
- Restauración de copias.
- Funcionamiento offline mediante Service Worker.
- Sin cuentas, backend ni IA.


## Nota sobre recetas
Las cantidades son puntos de partida para lotes pequeños, no fórmulas universales. Las recomendaciones de levadura, nutrientes, temperatura, estabilización y carbonatación deben contrastarse con las instrucciones del fabricante y el método de elaboración utilizado.
